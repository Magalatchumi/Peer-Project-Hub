# 🚀 Peer Project Hub

### Build. Share. Connect.

**Peer Project Hub** is a student developer community platform designed to help students **showcase their projects, discover innovative work, explore technologies, and connect with other student developers.**

It provides a centralized space where students can build their developer profile and present their projects in a professional way.

---

## 🎯 Project Overview

Student projects are often scattered across different platforms or remain unseen by other students.

**Peer Project Hub** aims to solve this by providing a dedicated platform where students can:

- 📂 Showcase their projects
- 🔎 Discover projects created by other students
- 💻 Explore projects based on technologies
- 👤 Build and customize their developer profile
- 📊 Track their project activity
- 🤝 Connect and collaborate with other developers

The current version focuses on building a complete and responsive **frontend experience**, with backend integration planned for the next phase.

---

## ✨ Key Features

### 🔐 Authentication & User Management

- User Signup and Login
- Persistent login sessions
- Authentication-based Navbar
- Profile dropdown with quick actions
- Logout functionality
- Client-side session management using `localStorage`

### 👤 Developer Profiles

- Personalized developer profile
- Profile picture / avatar
- Bio and developer information
- Skills & technologies
- GitHub, LinkedIn and Portfolio links
- Edit Profile functionality
- Developer statistics
- Project gallery

### 📂 Project Management

- Create new projects
- Edit existing projects
- Delete projects
- Project status tracking
- Technology selection
- Category and difficulty classification
- Project preview before publishing
- **Project Completeness Score** to indicate how complete a project submission is

### 🔎 Project Discovery

- Explore all available projects
- Search by project title or description
- Filter by:
  - Category
  - Status
  - Difficulty
- Project cards with important project information
- Pagination for browsing projects
- Detailed project showcase page

### 📊 Dashboard

- Personal project dashboard
- My Projects section
- Total project count
- Total views
- Total likes
- Quick project management actions
- Empty state for users without projects

### 💻 Technology Explorer

Explore projects based on popular technologies such as:

- React
- Node.js
- Python
- JavaScript
- MongoDB
- And more

Each technology displays its associated project count and provides quick access to relevant projects.

### 📱 Responsive UI/UX

- Desktop optimized layout
- Tablet responsive design
- Mobile-friendly interface
- Responsive navigation
- Clean card-based project layouts
- Consistent typography and spacing
- Smooth hover and transition effects
